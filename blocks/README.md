# Blocks

Open index.html to play. The board is light. Clearing a line changes the theme and can trigger one of 10 effects: Spark, Bonus, Extra life, Carve, Fresh tray, Double, Blast, Recolor, Easy pieces, or Gold.

You start with 3 lives. When no piece fits, use a life to clear space and keep your score.

On game over, type your name and press Save score. It is stored in the Firebase leaderboard.

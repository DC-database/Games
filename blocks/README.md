# Blocks

One file: `index.html`. Double-click it to play. The board, the pieces, and the dark background are all inside that file.

## Upload to GitHub

1. Go to your repository.
2. Click **Add file**, then **Upload files**.
3. Upload this new `index.html`. If GitHub says the file already exists, choose to replace it.
4. You can delete the old `style.css`, `game.js`, and `firebase-firestore.rules.txt`. This game does not use them.
5. Commit.

Opening the file from a folder on your computer now looks the same as the finished game. A raw file page on GitHub will still look like code. To get a playable link, use **Settings → Pages → Deploy from a branch → main → / (root)**. The game will be at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.
